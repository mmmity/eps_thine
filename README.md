# eps_thine
May the eps be thine! Discrete Optimization course work

Сборка всего подряд: `mkdir -p build && cmake -B build && cmake --build build`

После сборки можно запускать тесты при помощи `python3 run_tests.py <setcover|knapsack|coloring>`

Результаты запусков тестов пока что лежат в файле `<target>/results.txt`, а ответ на каждый конкретный тест в файле `<target>/results/<test>`

Отчеты по задачам лежат в файлах `<tartet>/README.md`
