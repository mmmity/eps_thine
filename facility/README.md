# Постановка задачи

На плоскости есть N мест для открытия магазинов и M покупателей. У каждого магазина $i$ есть стоимость открытия $s_i$ и вместимость $c_i$. У каждого покупателя $j$ есть спрос $d_j$. Нужно открыть некоторые магазины и распределить по ним покупателей так, чтобы минимизировать сумму $s_i$ по всем открытым магазинам плюс сумму расстояний от покупателей до назначенных им магазинов. При этом для каждого открытого магазина сумма $d_j$ назначенных в него покупателей не должна превышать $c_i$. Каждому покупателю назначается только один магазин. 


Формально: $x_i$ - бинарная переменная, открыт ли $i$-й магазин, $y_{i,j}$ - бинарная переменная, ходит ли покупатель $j$ в магазин $i$. Пусть $p_{i, j}$ - расстояние на плоскости от $i$-го магазина до $j$-го покупателя.

Минимизируем функцию $\sum_{i=1}^N s_i x_i + \sum_{i=1}^N \sum_{j=1}^M p_{i, j} y_{i, j}$ с ограничениями:
- для всех $j$: $\sum_{i=1}^N y_{i, j} = 1$ - покупателю назначен только один магазин
- для всех $i$: $\sum_{j=1}^M d_j y_{i, j} \leq c_i$ - суммарный спрос покупателей не больше вместимости магазина
- для всех $i, j$: $y_{i, j} \leq x_i$ - покупатель ходит только в открытые магазины


# Решение 1

Простейший жадник - по умолчанию считаем что все магазины открыты, для каждого покупателя жадно выбираем ближайший свободный, после чего магазины которые ни разу не были использованы закрываем обратно.

# Решение 2

Пробуем сделать branch and bound. Тут на самом деле сложно, потому что если выбирать открывать или не открывать магазин еще несложно, то распределять людей по магазинам уже дофига вариантов. Поэтому людей я по прежнему распределяю жадно, что делает оценку сверху плохой. Еще не очень понятно как сделать хорошую оценку снизу, я беру сумму расстояний до ближайших магазинов для каждого человека, плюс набираю суммарный спрос как в рюкзаке. Это тоже довольно тупая оценка, но придумать хорошую трудно... Еще я заранее сортирую магазины по вместимость / стоимость, чтобы не сортировать при подсчете нижней оценки.
