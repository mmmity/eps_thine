# Решение 1 
Жадная покраска в произвольном порядке, где вершина красится в mex цветов ее покрашенных соседей.

Результат:

- test gc_50_3: 9
- test gc_70_7: 23
- test gc_100_5: 22
- test gc_250_9: 97
- test gc_500_1: 19
- test gc_1000_5: 129

Не пробит ни один порог, что в общем-то ожидаемо

# Решение 2
Запустим 500 раз на случайном порядке вершин и выберем лучшее решение. Таким образом мы избавляемся от возможности, что исходный порядок плохой. А еще повышаем шансы найти хороший порядок, поскольку для оптимальной покраски он существует.

Результат:

- test gc_50_3: 7
- test gc_70_7: 20
- test gc_100_5: 19
- test gc_250_9: 91
- test gc_500_1: 18
- test gc_1000_5: 123

Пробили все нижние пороги.
