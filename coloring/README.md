# Решение 2
Запустим 500 раз на случайном порядке вершин и выберем лучшее решение. Таким образом мы избавляемся от возможности, что исходный порядок плохой. А еще повышаем шансы найти хороший порядок, поскольку для оптимальной покраски он существует.

- test gc_100_5: 19

# Решение 3
Используем идею локального спуска из лекции: пусть была какая-то раскраска 1, если поставить вершины так, чтобы вершины одного цвета из этой покраски шли подряд и применить жадный алгоритм, то результирующая раскраска 2 точно будет не хуже. Для увеличения рандомности будем каждый раз перемешивать цвета, а так же перемешивать порядок вершин одного цвета. Сделаем 200 шагов спуска и ~~сто шагов назад~~ запустимся так 100 раз, каждый раз на случайном порядке вершин.
