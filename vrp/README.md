# Постановка задачи

На плоскости есть $N$ точек. Первая точка - склад, остальные - клиенты. У каждого клиента $i$ есть спрос $d_i$. Также есть $V$ машин емкости $c$. Требуется распределить клиентов по машинам, а так же найти оптимальные пути для каждой машины, минимизировав сумму маршрутов машин так, чтобы каждый клиент был посещен один раз и сумма спросов клиентов $i$-й машины не превышала $c$.

Для формальной постановки введем бинарные переменные: $x_{i, j, k}$ - 1 если машина $i$ едет из $j$-й точки в $k$-ю. (Далее все суммы не включают верхнюю границу)

Тогда функция, которую мы минимизируем - $\sum_{i=0}^V\sum_{j=0}^N\sum_{k=0}^N x_{i, j, k} \cdot p(j, k)$

А условия:
- $\sum_{i=0}^V \sum_{j=1}^N x_{i, j, k} = 1$ для $k=1...N$ - каждый клиент, то есть все точки кроме нулевой, посещен ровно один раз
- $\sum_{j=0}^N x_{i, j, k} = \sum_{j = 0}^N x_{i, k, j}$ для всех $i = 0...V$, $k = 1...N$ - каждая машина, въезжая в точку, выезжает из нее
- $\sum_{k=1}^N x_{i, 0, k} \le 1$ - машина выезжает со склада не более 1 раза
- $\sum_{k=1}^N x_{i, k, 0} \le 1$ - машина возвращается на склад не более 1 раза
- $\sum_{j=1}^N d_j \sum_{k = 1, k \ne j}^N x_{i, j, k} \le c$ для всех $i$ - сумма спросов клиентов $i$-й машины не превышает capacity.
- Для любого множества $S \subset \{1,...,N-1\}$  и для любого $i$ сделаем $\sum_{j\in S} \sum{k \in S} x_{i, j, k} \le |S| - 1$ - это чтобы не было замкнутых подциклов.


Понятная идея - распределить клиентов по машинам, а дальше решить tsp для каждой машины независимо. Остается только научиться распределять клиентов по машинам (и нормально решить tsp...)

# Решение 1
Будем набирать каждую машину жадно - проходиться по еще не взятым клиентам и отдавать ей если можем. Отсортируем клиентов по координате $x$, чтобы множества клиентов были лучше локализованы. Далее, для каждой машины решим tsp как в решении 1 задачи tsp, то есть жадно.

# Решение 3
Казалось бы, хочется чтобы множества на которые мы разбиваем точки, были достаточно хорошо кластеризованы. Поэтому здесь я делаю жадник, чем-то похожий на алгоритм кластеризации KMeans, только адаптированный под нашу задачу (на самом деле, может быть можно было бы реализовать более канонический KMeans, но я адаптировал как мог). Как минимум, этот KMeans выполняется последовательно. Мы выбираем одну еще не распределенную точку, ее же ставим центроидом кластера. Далее добавляем ближайшую нераспределенную к центроиду из тех которые можно, чтобы сумма спросов не превысила емкость машины, пока такие существуют. Это один кластер. Чтобы справиться с недетерминированностью выбора первой точки кластера, берем ее рандомно и запускаемся 500 раз.
